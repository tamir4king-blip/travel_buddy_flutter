1. TECH STACK
================================================================================

FRAMEWORK & LANGUAGE
--------------------
- Flutter 3.27.4 (Cross-platform UI framework)
- Dart 3.6.2 (Programming language)
- Platform: Web (Chrome), iOS, Android ready

STATE MANAGEMENT
----------------
- flutter_riverpod ^2.6.1
  - StateNotifier pattern for reactive state
  - Provider-based dependency injection
  - Immutable state with copyWith patterns

NAVIGATION
----------
- go_router ^14.8.1
  - Declarative routing
  - Deep linking support
  - Shell routes for bottom navigation

UI & ANIMATIONS
---------------
- flutter_animate ^4.5.2
  - Declarative animation chains
  - Fade, slide, scale effects
  - Staggered list animations

- lucide_icons ^0.460.0
  - Modern icon set
  - Consistent visual language

UTILITIES
---------
- intl ^0.20.2 (Internationalization)

- shared_preferences ^2.5.3 (Local storage)

ARCHITECTURE PATTERN
--------------------
- Clean Architecture inspired
- Feature-first folder structure
- Separation of concerns:
  * Presentation (Screens, Widgets)
  * Business Logic (Providers, Notifiers)
  * Data (Models, Registries)

================================================================================
3. WORKFLOW
================================================================================

USER FLOW
---------

1. HOME SCREEN
   - View profile summary (level, XP, streak)
   - Quick stats overview
   - Featured achievements/quests

2. ACHIEVEMENTS TAB
   - Browse all achievements (15 base achievements)
   - Filter by tier (Bronze, Silver, Gold, Platinum)
   - Filter by collection (Cities, Nature, Food, Culture, Photo)
   - Search achievements
   - Claim achievements:
     * Quick claim (instant, full XP)
     * Retroactive claim (past date, 80% XP)

3. QUESTS TAB
   - Browse 150+ side quests
   - Filter by category (18 categories)
   - Filter by difficulty (Easy, Medium, Hard, Epic)
   - Complete quests for skill XP

4. SKILLS TAB
   - View 44 skill groups
   - Track skill levels and XP
   - Skill categories:
     * Outdoor & Nature
     * Water Sports
     * Extreme & Adrenaline
     * Sports & Fitness
     * Food & Drink
     * Culture & Arts
     * Social & Nightlife
     * Urban & Photography
     * Travel & Freedom

5. PROFILE TAB
   - User stats
   - Level progression
   - Settings


DEVELOPMENT WORKFLOW
--------------------

1. Start development server:
   > flutter run -d chrome

2. Hot reload (preserves state):
   Press 'r' in terminal

3. Hot restart (resets state):
   Press 'R' in terminal

4. Build for production:
   > flutter build web

5. DATA MODELS
================================================================================

ACHIEVEMENT
-----------
- id: String
- title: String
- description: String
- iconName: String?
- tier: AchievementTier (bronze, silver, gold, platinum)
- xpReward: int
- latitude/longitude: double? (location)
- claimRadius: double?
- collectionId: String?
- tags: List<String>
- isUnlocked: bool
- unlockedAt: DateTime?
- visitDate: DateTime? (for retroactive)
- photos: List<String>
- notes: String?
- isRetroactive: bool

SIDE QUEST
----------
- id: String
- title: String
- description: String
- category: String (18 categories)
- skillType: String (links to skill)
- difficulty: QuestDifficulty (easy, medium, hard, epic)
- xpReward: int
- verification: VerificationMethod
- isRepeatable: bool
- maxCompletions: int
- completionCount: int
- isCompleted: bool

SKILL GROUP
-----------
- id: String
- name: String
- icon: String (emoji)
- description: String
- categories: List<String>
- maxLevel: int (50)
- xpPerLevel: int (varies)
- gradientStart: String (hex color)
- gradientEnd: String (hex color)

USER PROFILE
------------
- id: String
- displayName: String
- level: int
- xp: int
- avatarUrl: String?

================================================================================
7. GETTING STARTED
================================================================================

PREREQUISITES
-------------
- Flutter SDK 3.27.4+
- Dart SDK 3.5.0+
- Chrome browser (for web development)

INSTALLATION
------------
1. Clone the repository
2. Navigate to project directory:
   > cd travel_buddy_flutter-main

3. Get dependencies:
   > flutter pub get

4. Run the app:
   > flutter run -d chrome

BUILD
-----
Web:     > flutter build web
Android: > flutter build apk
iOS:     > flutter build ios
